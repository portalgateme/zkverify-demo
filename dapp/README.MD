
## Installation

```bash
$ yarn install
```

## Running the app

```bash
# Ensure the .env is set correctly
$ cp .env.example .env.local
# set NEXT_PUBLIC_CHAIN_ID=31337 for local hardhat
# set NEXT_PUBLIC_SUPPORTED_CHAINS=31337 for local hardhat

# Running
$ yarn dev
```

Open browser at `http://localhost:8080` to do the deposit and withdraw
